## 🔨 단계별 조립

### 1단계: ESP32 기본 연결

1. **브레드보드에 ESP32 장착**
   - ESP32를 브레드보드 중앙에 배치
   - 핀이 브레드보드에 잘 꽂히는지 확인

2. **전원 레일 연결**
   - 브레드보드 + 레일 → ESP32 VIN (5V)
   - 브레드보드 - 레일 → ESP32 GND
   - ESP32 3.3V → 센서용 전원 레일

### 2단계: 74HC595 연결

#### 첫 번째 74HC595 (하위 8비트)

```
74HC595 핀 연결:
Pin 1-7, 15 (Q0-Q7) → 릴레이 IN0-IN7
Pin 8 (GND) → GND
Pin 9 (Q7') → 두 번째 74HC595 Pin 14
Pin 10 (MR) → 5V
Pin 11 (SH_CP) → ESP32 GPIO 13
Pin 12 (ST_CP) → ESP32 GPIO 12
Pin 13 (OE) → ESP32 GPIO 5
Pin 14 (DS) → ESP32 GPIO 14
Pin 16 (VCC) → 5V
```

#### 두 번째 74HC595 (상위 8비트)

```
74HC595 핀 연결:
Pin 1-7, 15 (Q0-Q7) → 릴레이 IN8-IN15
Pin 8 (GND) → GND
Pin 10 (MR) → 5V
Pin 11 (SH_CP) → 첫 번째 74HC595 Pin 11
Pin 12 (ST_CP) → 첫 번째 74HC595 Pin 12
Pin 13 (OE) → 첫 번째 74HC595 Pin 13
Pin 14 (DS) → 첫 번째 74HC595 Pin 9
Pin 16 (VCC) → 5V
```

### 3단계: 센서 연결

#### 근접 센서 (LJ12A3-4-Z/BX)

```
갈색 선 → 12V
파란색 선 → GND
검은색 선 → ESP32 GPIO 18 (4.7kΩ 풀업 저항 권장)
```

⚠️ **주의**: 근접 센서는 NPN, NO(Normally Open) 타입이어야 합니다!

#### PZEM-004T V3.0

```
5V → ESP32 5V (또는 외부 5V)
GND → GND
TX → ESP32 GPIO 16 (RX)
RX → ESP32 GPIO 17 (TX)
```

### 4단계: 릴레이 모듈 연결

```
릴레이 모듈:
VCC → 12V (또는 5V, 모듈에 따라)
GND → GND
IN0-IN15 → 74HC595 출력

릴레이 출력:
NO (Normally Open) → 부하 (펌프, 밸브)
COM (Common) → 전원 (+)
```

### 5단계: 워터 펌프 & 밸브 연결

```
워터 펌프:
+ → 릴레이 R8 NO
- → 12V GND

급수 밸브:
+ → 릴레이 R4 NO
- → 12V GND
```

| 구성품 | 전압 | 전류 | 비고 |
|--------|------|------|------|
| ESP32 | 5V | 500mA | VIN 핀 사용 |

| 근접 센서 | 12V | 10mA | NPN 타입 |
| PZEM-004T | 5V | 50mA | |

| 워터 펌프 | 12V | 1-2A | 사양 확인 |
| 급수 밸브 | 12V | 300mA | |

**권장 전원**: 12V 3A 어댑터 + 5V 레귤레이터

### 전원 회로

```
12V 3A 어댑터
      │
      ├──► 근접 센서 (12V)
      ├──► 워터 펌프 (릴레이 통해)
      ├──► 급수 밸브 (릴레이 통해)
      │
      └──► LM2596 DC-DC (12V → 5V)
                │
                ├──► ESP32 (5V)
                ├──► 74HC595 (5V)
                ├──► PZEM-004T (5V)
                └──► 릴레이 모듈 (5V)
```

## 🧪 테스트

### 1. 전원 테스트

```bash
1. 12V 어댑터 연결
2. 멀티미터로 전압 확인
   - 12V 레일: 11.5V ~ 12.5V
   - 5V 레일: 4.8V ~ 5.2V
   - 3.3V (ESP32): 3.2V ~ 3.4V
```

### 2. ESP32 테스트

```bash
1. USB 케이블로 ESP32 연결
2. Arduino IDE 시리얼 모니터 오픈
3. Blink 예제 업로드
4. LED 깜빡임 확인
```

### 3. 센서 테스트

```bash
1. 펌웨어 업로드
2. 시리얼 모니터에서 "STATUS" 입력
3. 센서 값 확인:
   - 근접센서: CLEAR/DETECTED
   - PZEM: 전압/전류 값
```

### 4. 릴레이 테스트

```bash
1. 시리얼 모니터에서 "TEST" 입력
2. 모든 릴레이 순차 동작 확인
3. "SCAN" 입력으로 개별 테스트
```

### 5. 급수 시스템 테스트

```bash
1. 물통 준비
2. "WATER:2,3,2" 입력
3. 동작 확인:
   - 모터 작동
   - 센서 감지
   - 밸브 개폐
```

## ⚠️ 안전 주의사항

### 전기 안전
- ⚡ 220V 작업시 반드시 전원 차단
- 🔌 적절한 용량의 퓨즈 사용
- 🧰 절연된 공구 사용
- 👷 전문가 자문 권장

### 물 안전
- 💧 방수 처리된 케이스 사용
- 🌊 물이 전자부품에 닿지 않도록 배치
- 🔄 역류 방지 밸브 설치
- 🚰 정기적인 파이프 점검

### 시스템 안전
- 🔴 긴급 정지 스위치 설치
- 📊 과급수 방지 타이머 설정
- 🔍 정기 점검 스케줄 수립
- 📝 점검 기록 유지

## 🛠️ 문제 해결

### LED가 켜지지 않음
- 전원 연결 확인
- 전압 측정
- USB 케이블 교체

### 릴레이가 동작하지 않음
- 74HC595 연결 확인
- 전원 전압 확인
- "SCAN" 명령으로 개별 테스트

### 센서 값이 이상함
- 센서 전원 확인
- 연결 상태 확인
- 센서 교체

### 급수가 안됨
- 펌프 전원 확인
- 밸브 전원 확인
- 파이프 막힘 확인
- 릴레이 동작 확인
